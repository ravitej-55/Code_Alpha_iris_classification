# Iris Flower Classification

This project trains a machine learning model to classify Iris flower species (setosa, versicolor, virginica) based on flower measurements using Scikit-learn.

## Features
- Load the Iris dataset using Scikit-learn.
- Train a RandomForest classification model.
- Evaluate model accuracy and generate confusion matrix.
- Predict species for custom inputs.
- Includes training script, evaluation script, and prediction script.
